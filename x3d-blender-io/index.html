Method in one paragraph

tools/astlib.py walks every module: classes (Blender bases, bl_*, operator properties), every def (methods and nested), lazy vs top-level imports, McCabe complexity, nesting depth, a position-free body hash, calls (resolved statically: local, nested, imported, self., module.), X3D node/field literals classified by context (emitted tag, compare, dispatch-table key, getter argument) and Blender vocabulary. tools/era.py repeats it on every first-parent commit via git show. Graphify was not found on this Mac and nothing was installed.

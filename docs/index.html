X3D teardowns

Six code bases taken apart with abstract syntax trees (Python ast, the TypeScript parser, an XML walk of every X3D file), git history and the X3D 4.1 Unified Object Model. Every figure is a 3D X3D 4.0 scene that you can orbit and hover, rendered by X_ITE in the browser; every scene passes the x3d_mcp validator. Measured numbers are plain; heuristics are labelled inferred. Generated 2026-11-13.
